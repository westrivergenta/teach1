# まなびランド アップロード手順

GitHub Pages で公開するときのファイル一式です。

## このフォルダの中身

全部リポジトリの一番上（同じフォルダ）に置きます。`icons` はフォルダごと置きます。

| ファイル | 内容 |
| --- | --- |
| `index.html` | まなびランド本体 |
| `config.js` | ランキングサーバーの接続先と公開用キー（スワップ4と同じもの） |
| `maruo-opening.js` | まるおゲーム共通オープニング v1.0.0（配布物のまま。改変しない） |
| `maruo-ranking.js` | まるおゲーム共通ランキング v1.0.0（配布物のまま。改変しない） |
| `manifest.webmanifest` | ホーム画面に追加したときのアプリ名とアイコンの設定 |
| `icons/` | ポコのアイコン（180・192・512・1024px） |

`config.js`・`maruo-opening.js`・`maruo-ranking.js` は、スワップ4のリポジトリ（westrivergenta/puzzlegame1）にあるものをそのままコピーしています。

## 手順

1. GitHubで新しいリポジトリを作る（例：`manabiland`）
2. ファイルと `icons` フォルダをアップロードする（README.md は置いても置かなくてもよい）
3. Settings → Pages で、Branch を `main` / `(root)` にして Save
4. 数分待って、表示されたURLを開く

## 公開後の確認

- [ ] GitHubの画面で `config.js` を開き、URLとキーが入っている
- [ ] 起動すると「まるおゲーム」のオープニングが出る
- [ ] ブラウザのタブと、ホーム画面に追加したときのアイコンがポコになっている
- [ ] 学年と教科を選ぶと、教科を選ぶ画面に「🏆 5回 遊ぶと ランキングに のるよ！」と出る
- [ ] 同じ教科を5回遊ぶと、結果画面に「じこベスト 平均○点／全体○位」が出る
- [ ] 「🏆 ランキング」に自分の名前が出る
- [ ] Supabaseの Table Editor で、`manabi-g○-○○` の gameId の行が増えている

## ランキングの仕様

- gameId は学年×教科ごと（例：`manabi-g4-math`、`manabi-g4-all`）。公開後は変えない
- 5回以上遊んだ人だけが載る。順位は直近5回の平均点の最高値
- 平均点が同じなら、残り時間（正解したときの制限時間までの残り秒数の合計）が多い人が上
- 送る点数 ＝ 直近5回の合計点 × 15000 ＋ 残り時間の合計（秒）
- べつの学年・教科に切りかえると、その教科の gameId でページを開き直す（キットの「init は1ページ1回」を守るため）
