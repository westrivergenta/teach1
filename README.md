# まなびランド アップロード手順

GitHub Pages で公開するときのファイル一覧と手順です。

## リポジトリに置くファイル

全部同じフォルダ（リポジトリの一番上）に置きます。

| ファイル | 入っているか | 入手先 |
| --- | --- | --- |
| `index.html` | このzipに入っています | ― |
| `config.js` | 入っていません | 既存のまるおゲーム（スワップ4など）のものをそのままコピー |
| `maruo-opening.js` | 入っていません | まるおゲーム共通キットの配布物をそのままコピー（改変しない） |
| `maruo-ranking.js` | 入っていません | まるおゲーム共通キットの配布物をそのままコピー（改変しない） |

`config.js` は新しく作らず、URLとキーが入っている既存のものを使ってください。空のファイルで上書きすると「ランキングサーバーが未設定です」と表示されます。

## 手順

1. GitHubで新しいリポジトリを作る（例：`manabiland`）
2. 上の4つのファイルをアップロードする
3. Settings → Pages で、Branch を `main` / `(root)` にして Save
4. 数分待って、表示されたURLを開く

## 公開後の確認

- [ ] GitHubの画面で `config.js` を開き、URLとキーが入っている
- [ ] 学年と教科を選んで、教科を選ぶ画面に「🏆 5回 遊ぶと ランキングに のるよ！」と出る
- [ ] 同じ教科を5回遊ぶと、結果画面に「じこベスト 平均○点／全体○位」が出る
- [ ] 「🏆 ランキング」に自分の名前が出る
- [ ] Supabaseの Table Editor で、`manabi-g○-○○` の gameId の行が増えている

## ランキングの仕様

- gameId は学年×教科ごと（例：`manabi-g4-math`、`manabi-g4-all`）。公開後は変えない
- 5回以上遊んだ人だけが載る。順位は直近5回の平均点の最高値
- 平均点が同じなら、残り時間（正解したときの制限時間までの残り秒数の合計）が多い人が上
- 送る点数 ＝ 直近5回の合計点 × 15000 ＋ 残り時間の合計（秒）
